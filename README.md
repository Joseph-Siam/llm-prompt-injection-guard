# LLM Prompt-Injection Guard

**AI Security | Python | FastAPI | Security Testing**

## Project Overview

LLM Prompt-Injection Guard is a team-developed cybersecurity project designed to explore ways to detect and defend against prompt-injection attacks targeting AI chatbots.

The project uses a Python and FastAPI-based guard prototype to evaluate suspicious user inputs and untrusted retrieved content before they influence a simulated chatbot.

**Status:** In Progress — Prototype Testing and Evaluation

## Project Objectives

- Identify potential prompt-injection attempts.
- Evaluate detection and risk-based blocking responses.
- Test multilingual and multi-turn attack scenarios.
- Review model-output checks and audit logs.
- Identify weaknesses and improve defensive approaches.

## How It Works

The prototype follows this workflow:

1. **Input:** Receive a user prompt or retrieved content.
2. **Detection:** Analyze the input for potential prompt-injection attempts.
3. **Response:** Apply the prototype's detection and blocking logic.
4. **Testing:** Evaluate behavior using prepared attack scenarios.
5. **Review:** Examine audit logs and dashboard results to identify weaknesses.
